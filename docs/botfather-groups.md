# BotFather / группы: автозагрузка ссылок

Чтобы бот видел обычные сообщения со ссылками в группах (не только команды и упоминания):

## 1. Отключить Group Privacy

В [@BotFather](https://t.me/BotFather):

```
/setprivacy
```

Выбрать `@komuzik_bot` → **Disable**.

Без этого Telegram не присылает боту обычные сообщения в группе.

## 2. Добавить бота в группу

- Право **отправлять сообщения** обязательно.
- После Disable privacy бот будет отвечать на сообщения с поддерживаемыми ссылками.

## 3. Префиксы (как в инлайне)

В **начале** сообщения: `music` / `audio`, `360` / `480` / `720` / `1080` (+ optional `p`).
Ссылка может быть в любом месте текста. Без префикса YouTube → 720p.
