# Inline YouTube search — design

Дата: 2026-07-20

## Цель

`@komuzik_bot <текст>` без ссылки показывает результаты поиска YouTube; выбор запускает ту же inline-загрузку, что и по ссылке.

## Поведение

| Query | Результат |
|-------|-----------|
| URL (+ префиксы) | как сейчас |
| текст без URL | до 5 video articles из `ytsearch` |
| пусто | подсказка: ссылка или поисковый запрос |

После выбора: download video, качество из `/settings` (как inline без префикса), `source=inline`. При поиске — `track_search`.

## Вне scope

- `music` / `720` перед поисковым текстом
