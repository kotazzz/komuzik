# Design: постраничный `/help` + команда `/info`

Дата: 2026-07-20  
Статус: approved (чат)

## Цель

Разбить справку на оглавление и подробные страницы по разделам. Админам бота — отдельная ветка справки. Отдельная команда `/info` с автором, исходником и указанием `/report`.

## Решения (зафиксированы)

- Навигация: **оглавление + кнопки разделов**; внутри раздела — подробный текст и «← Назад» к оглавлению.
- Админ: на пользовательском оглавлении кнопка **«🛠 Для админа»** (только `ADMIN_USER_IDS`) → своё оглавление админских разделов.
- `/help` и `/info` — **разные команды**.

## Поведение `/help`

1. `/help` отвечает новым сообщением: текст оглавления + inline-кнопки разделов.
2. Клик по разделу **редактирует** то же сообщение (текст страницы + «← Назад»).
3. «← Назад» возвращает к соответствующему оглавлению (пользовательскому или админскому).
4. С админ-оглавления «← Назад» ведёт на **пользовательское** оглавление.
5. Бан-guard: как у текущих команд (`_reject_if_banned`).
6. Не-админ, нажавший админ-callback: без изменений UI (тихо или короткий «нет доступа» в `answer`).

### Callback data

- `help_toc` — пользовательское оглавление
- `help_u_<slug>` — пользовательский раздел
- `help_a_toc` — админское оглавление
- `help_a_<slug>` — админский раздел

Префикс `help_` обрабатывается в `callback_handler`.

### Пользовательские разделы (`help_u_*`)

| slug | Кнопка | Содержание (подробно) |
|------|--------|------------------------|
| `start` | Старт | Ссылка → выбор формата → загрузка; куда писать |
| `platforms` | Платформы | YouTube (видео/аудио/качество), Shorts, TikTok, Twitter/X, Pinterest |
| `playlists` | Плейлисты | Превью, исключения ответом, пачки, стоп, суточный лимит |
| `inline` | Inline | `@бот ссылка`, `music`, качество; нужен `/start` в ЛС |
| `groups` | Группы | Автозагрузка ссылок; `/settings` для админов чата |
| `commands` | Команды | `/start` `/settings` `/search` `/stats` `/report` `/info` `/privacy` |

На оглавлении: краткий заголовок + подсказка «выберите раздел»; упоминание «об авторе и исходниках — `/info`».

Если отправитель — админ бота, внизу кнопок: **«🛠 Для админа»** → `help_a_toc`.

### Админские разделы (`help_a_*`)

Только если `user_id ∈ download_limiter.ADMIN_USER_IDS` (и при показе кнопки, и при обработке callback).

| slug | Кнопка | Содержание |
|------|--------|------------|
| `panel` | Панель | `/admin`, кнопки лимитов на панели |
| `limits` | Лимиты | `/setconcurrent`, `/setplaylistlimit`, `/setuserlimit`, `/unsetuserlimit` |
| `bans` | Блокировки | `/ban`, `/unban`, поведение в ЛС/группах |
| `users` | Пользователи | `/users`, `/user`, вкладки, история |
| `storage` | Хранилище | `/setstorage`, `/unsetstorage` |
| `post` | Рассылка | `/post` ответом на сообщение |

## Поведение `/info`

Отдельный handler (не страница `/help`).

Текст:
- исходный код: https://github.com/kotazzz/komuzik
- автор: Kotaz
- баги и жалобы: команда `/report`

Опционально: кнопка-ссылка на GitHub (`Button.url`).  
Бан-guard как у `/help`.

## Реализация (границы)

- Новый модуль `src/komuzik/help_pages.py`: тексты страниц, сборка кнопок оглавления/страницы, константы slug.
- `handlers.py`: `help_handler`, `info_handler`, ветка callback `help_*`.
- Регистрация `pattern="/info"` (или `^/info(?:@\w+)?`).
- `config.yaml` / `MSG_HELP`: больше не источник текста `/help` (можно оставить неиспользуемым или упростить до одной строки-заглушки — не блокер).
- README: кратко обновить список команд (`/info`, постраничный `/help`).

## Вне scope

- Перевод справки на другие языки.
- Cookies/авторизация для TikTok/YouTube (отдельная тема).
- Изменение логики админ-команд — только документация в справке.

## Тесты

- Юнит: оглавление пользователя без админ-кнопки; с админ-кнопкой при флаге admin.
- Юнит: тексты/slug всех страниц не пустые; callback data в лимите Telegram (~64 байт).
- Юнит: `format` страниц содержит ключевые команды (`/report`, `/admin`, github URL в `/info` handler или константе).

## Критерии готовности

- `/help` открывает оглавление с кнопками разделов.
- Разделы редактируют сообщение; «← Назад» работает.
- Админ видит «🛠 Для админа» и админ-разделы; обычный пользователь — нет.
- `/info` — отдельное сообщение с GitHub, Kotaz, `/report`.
