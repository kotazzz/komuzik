# Admin Ban (Block B) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ban users by id with a reason; DM/inline show a fixed template; groups stay silent; `/report` still works.

**Architecture:** SQLite `user_bans` + repository CRUD. Early `enforce_ban` guard in handlers for DM/inline/callbacks; group handlers return silently. Admin `/ban` `/unban` + `/admin` hints.

**Tech Stack:** Python 3.11, Telethon, SQLite, existing `StatsRepository` / `BotHandlers`.

## Global Constraints

- Template exactly:
  ```
  🚫 Вы заблокированы.
  Причина: {reason}
  Если ошибка — /report
  ```
- DM + inline → template; groups → silent.
- `/report` allowlisted for banned users.
- Cannot ban `admin_user_ids`.
- Spec: `docs/superpowers/specs/2026-07-20-admin-ban-design.md`.
- Commits: `feat(admin): …`; push after chunks.

### Task 2: Guard + `/ban` `/unban` + `/admin`

**Constant:**

```python
def format_ban_message(reason: str) -> str:
    return (
        "🚫 Вы заблокированы.\n"
        f"Причина: {reason}\n"
        "Если ошибка — /report"
    )
```

**`async def _reject_if_banned(self, event, user_id, *, chat_is_group: bool) -> bool`:**
- If admin → False (continue)
- If not banned → False
- If group → True (stop, no reply)
- Else reply/edit with `format_ban_message`; return True

**Wire:**
- Start of `message_handler` (after extract user): if text starts with `/report` → skip ban; else if `_reject_if_banned` → return
- Callbacks: same (except maybe report_cancel if needed)
- Inline query + chosen: ban → show template, no download
- Playlist/other paths covered if they go through message_handler / callbacks

**Commands:**
- `/ban <id> <reason…>` — validate id int; refuse admin targets; `ban_user`
- `/unban <id>` — `unban_user`
- Silent non-admin
- `/admin` panel: add lines for ban commands + optional `Банов: N`

- [ ] Implement + manual smoke via pytest where possible
- [ ] Commit: `feat(admin): бан с причиной и guard`
