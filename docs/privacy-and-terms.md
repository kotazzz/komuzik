# Правила пользования и политика конфиденциальности бота Komuzik

Настоящий документ определяет порядок использования Telegram-бота Komuzik (далее — Бот) и условия обработки данных пользователей.

Бот предназначен для скачивания публично доступных видео и изображений по ссылке с платформ YouTube, TikTok, Twitter/X и Pinterest. Бот не является коммерческим сервисом.

Обращения по вопросам работы Бота, жалобам и запросам об удалении данных направляются командой /report.

---

## 1. Политика конфиденциальности

### 1.1. Состав обрабатываемых данных

Бот сохраняет следующие сведения:

1. идентификатор пользователя Telegram (Telegram ID);
2. имя пользователя (username) и отображаемое имя при их наличии;
3. ссылки и названия медиафайлов, запрошенных для скачивания, в том числе при обращении к Боту в режиме inline (@-упоминание);
4. сведения о загрузках: платформа, качество, источник запроса (личные сообщения, группа, inline), результат выполнения;
5. настройки пользователя;
6. текст обращений, направленных командой /report, а также вложения таких обращений; доступ к ним имеет администратор Бота;
7. при ограничении доступа — сведения о бане и указанная причина.

Текст сообщений в группах, не содержащих поддерживаемой ссылки, не сохраняется. Обработка сообщений в группе выполняется только при наличии поддерживаемой ссылки.

Полный текст инлайн-запроса в базу данных не записывается. При успешной или неуспешной загрузке через inline сохраняются сведения, указанные в пунктах 1–4 настоящего раздела.

Текст поисковых запросов, направленных командой /search, в базу данных не записывается. Запрос передаётся в YouTube для получения результатов. В статистике фиксируется факт выполнения поиска.

### 1.2. Цели обработки

Данные обрабатываются в целях:

1. учёта нагрузки и диагностики ошибок;
2. хранения настроек пользователя;
3. модерации, применения лимитов и рассмотрения обращений;
4. предоставления администратору истории загрузок.

Данные не продаются и не используются для рекламы. Сторонние сервисы аналитики и рекламные SDK не применяются.

### 1.3. Передача и обработка данных при работе Бота

1. Доставка сообщений и файлов осуществляется средствами Telegram.
2. Контент по запрошенной ссылке загружается с соответствующей платформы.
3. На сервере Бота файл хранится до завершения отправки пользователю, после чего удаляется.
4. В отдельных технических случаях медиафайл может кратковременно размещаться в служебном чате администратора с последующим удалением.

### 1.4. Срок хранения

Срок хранения данных не ограничен. Автоматическая очистка не производится.

### 1.5. Удаление данных

Запрос на удаление данных направляется командой /report. Запросы обрабатываются администратором вручную в разумный срок, как правило не превышающий 30 дней с момента получения обращения.

### 1.6. Ограничение доступа

Администратор вправе ограничить доступ пользователя к Боту. Оспаривание ограничения доступа осуществляется через /report.

## 2. Условия использования

### 2.1. Порядок предоставления

Бот предоставляется «как есть» в ознакомительных и развлекательных целях для личного использования. Бесперебойная работа Бота, доступность платформ и сохранность файлов не гарантируются.

### 2.2. Обязанности пользователя

Пользователь самостоятельно несёт ответственность за скачиваемый контент и соблюдение правил Telegram, правил платформ-источников и применимого законодательства, включая законодательство об авторском праве.

Допускается запрос только публично доступных по ссылке материалов. Запрос приватного или заведомо незаконного контента запрещён.

### 2.3. Ограничение ответственности

Оператор Бота:

1. не размещает контент на сторонних платформах;
2. не ведёт постоянное хранилище скачанных файлов пользователей;
3. не отвечает за содержание загрузок;
4. не отвечает за претензии правообладателей;
5. не отвечает за действия Telegram и платформ-источников;
6. не отвечает за сбои, вызванные изменением интерфейсов или средств защиты платформ;
7. не отвечает за убытки, связанные с использованием Бота или невозможностью его использования.

### 2.4. Полномочия администратора

Администратор вправе:

1. изменять лимиты и настройки Бота;
2. ограничивать доступ пользователей;
3. направлять служебные сообщения пользователям, ранее взаимодействовавшим с Ботом.

### 2.5. Обращения правообладателей

Если с помощью Бота распространяется контент, нарушающий авторские права, правообладатель вправе направить запрос об ограничении доступа к такому контенту в Боте командой /report. Запросы рассматриваются администратором.

### 2.6. Принятие условий

Использование Бота означает согласие с настоящим документом. При несогласии использование Бота и его добавление в чаты не допускаются.
